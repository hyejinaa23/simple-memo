# simple-memo

실행: https://hyejinaa23.github.io/simple-memo/ 에서 이메일·비밀번호(6자 이상)로 가입하고 이메일 확인 링크를 누른 후 로그인. 메모 저장·삭제 가능.

설정: Confirm email 켜짐. Site URL은 위 배포 주소. 공개용 키와 본인 조회·추가·삭제 RLS만 사용.

검증: Pages 배포·첫 화면 접속 및 RLS 활성화·3개 정책 확인. 가입 요청 계정 1건은 이메일 확인 대기 상태 확인. 실제 이메일 확인 이후 로그인·저장·새로고침 유지·삭제·로그아웃·재로그인 및 사용자 간 차단 검증은 아직 미완료.
